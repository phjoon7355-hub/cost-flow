전산회계 1급 회계원리 학습센터
================================

1. 시작하기
   - 회계원리_학습센터.html을 더블클릭하여 실행합니다.
   - 같은 브라우저에서 같은 파일을 열어야 내부 학습 기록이 이어집니다.
   - 권장 문제 수는 10문항입니다.
   - 전체 문제 방식에서는 기본문제와 변형문제를 섞어 출제합니다.
   - 20문항은 한 단원을 더 넓게 확인하는 집중 점검용입니다.

2. 원본 기초이론 문제를 먼저 푼 경우
   - 학습센터의 '오답노트' 메뉴로 이동합니다.
   - '기존 문제 오답 직접 등록'에서 틀린 번호를 입력합니다.
   - 예: 3, 7, 9

3. 숙달 기준
   - 틀린 문제는 '복습 필요' 상태가 됩니다.
   - 같은 개념을 연속 2회 맞히면 '숙달'로 표시됩니다.
   - 숙달되어도 과거의 오답 이력은 삭제되지 않습니다.

4. JSON 백업
   - '백업·복원' 메뉴에서 파일 이름을 원하는 한글 단원명으로 바꿉니다.
   - 예: 기초이론 학습기록, 재무회계 개념체계 오답
   - 'JSON 저장'을 누르면 문제은행과 전체 학습 기록이 UTF-8로 저장됩니다.
   - 단원이 끝날 때마다 백업하는 것을 권장합니다.

5. JSON 복원
   - '기록 합치기'
     현재 브라우저 기록을 그대로 유지하면서 JSON 기록을 추가합니다.
     단원별 백업이나 다른 컴퓨터의 기록을 한곳에 모을 때 사용합니다.
     동일한 풀이 기록은 한 번만 남깁니다.

   - '백업으로 교체'
     현재 브라우저 기록을 지우고 선택한 JSON의 저장 당시 상태로 되돌립니다.
     기기를 옮기거나 과거 백업으로 완전히 복구할 때 사용합니다.
     실행 전 현재 기록을 별도 JSON으로 저장하는 것이 안전합니다.

6. 새 단원 문제팩 추가
   - 교재 연습문제를 제공하면 OCR 오류를 바로잡고 전산회계 1급 수준의 응용문제로 구성합니다.
   - 교재 자료가 없어도 요청한 단원의 전산회계 1급 수준 문제를 새로 만들 수 있습니다.
   - 완성된 '문제팩 JSON'을 학습센터의 '백업·복원 > 새 단원 문제팩 가져오기'에서 선택합니다.
   - 문제팩을 가져와도 기존 학습기록과 오답노트는 유지됩니다.
   - 추가된 단원과 변형문제도 다음 전체 백업 JSON에 함께 저장됩니다.

7. 앞으로 새 단원을 추가할 때
   - 이 학습센터 파일과 최신 JSON 백업을 함께 보관합니다.
   - 새 문제는 문제팩 JSON으로 계속 추가할 수 있습니다.
   - 파일 이름과 위치를 바꾸지 않으면 브라우저 내부 기록을 계속 사용할 수 있습니다.

주의
----
브라우저 사용 기록이나 사이트 데이터를 삭제하면 내부 저장소의 기록도 지워질 수 있습니다.
JSON 백업 파일은 별도로 보관해 주세요.
