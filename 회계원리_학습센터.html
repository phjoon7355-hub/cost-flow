추천 학습 순서

약점 보강용

교재 전체 → AI 응용 전체 → 틀린 문제만 → 취약 유형 집중 → 틀린 유형 변형 → 통합 전체 점검

  1. 새 단원 시작교재 문제팩 → 전체 문제 → 가능한 문제 모두교재 핵심 유형부터 이해합니다.
  2. 이해 확인GPT 또는 Claude → 전체 문제 → 10문항새 상황에서도 풀리는지 확인합니다.
  3. 첫 복습통합 학습 → 틀린 문제만 → 5~10문항틀린 문제를 먼저 바로잡습니다.
  4. 약점 보강통합 학습 → 취약 유형 집중 → 5~10문항같은 유형을 반복해서 틀릴 때 선택합니다.
  5. 진짜 이해 확인통합 학습 → 틀린 유형 변형문제 → 5~10문항답 암기가 아닌 개념 이해를 확인합니다.
  6. 단원 마무리통합 학습 → 전체 문제 → 10문항오답이 줄었을 때 섞어서 최종 점검합니다.
문제팩 출처는 이렇게

처음에는 교재 문제팩, 응용 연습은 GPT·Claude 문제팩, 마지막 점검과 복습은 통합 학습을 추천합니다. 교재 문제팩이 없으면 학습센터 기본 문제 또는 가져온 문제팩부터 시작하세요.

학습 방식은 이렇게

전체 문제는 새 단원·마무리 점검, 틀린 문제만은 첫 복습, 취약 유형 집중은 반복 실수, 틀린 유형 변형문제는 개념 이해 확인에 사용합니다.

기존 문제 오답 직접 등록

원본 HTML에서 먼저 푼 경우, 문제팩 출처를 고른 뒤 틀린 번호를 입력하면 누적 오답에 포함됩니다.

누적 오답노트

숙달 후에도 이력은 삭제되지 않습니다.

새 단원 문제팩 가져오기

교재 자료가 있든 없든, 제가 만들어 드린 UTF-8 문제팩 JSON을 선택하면 새 단원과 변형문제가 학습센터에 추가됩니다.

기존 학습기록은 건드리지 않으며, 같은 문제 ID는 최신 문제팩 내용으로 갱신합니다.

JSON 백업·복원

파일 이름을 한글로 자유롭게 정할 수 있습니다. JSON 내부도 UTF-8 한글로 저장됩니다.

문제은행, 오답 이력, 숙달도와 설정을 한 파일로 저장합니다.

기록 합치기: 현재 기록을 유지하고 JSON의 기록을 더합니다. 단원별 백업을 모을 때 사용하세요.

백업으로 교체: 현재 기록을 지우고 JSON 저장 당시 상태로 되돌립니다. 기기 이전이나 복구할 때 사용하세요.

데이터 관리 원칙

브라우저 기록을 삭제하면 내부 저장소도 지워질 수 있습니다. 단원이 끝날 때마다 한글 이름으로 JSON 백업을 저장해 두세요.
